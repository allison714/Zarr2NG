# Zarr2NG

**Superseded.** This is the 7 October 2026 snapshot of the Zarr Batch Converter: convert microscope images to OME-Zarr on the lab's Neuroglancer server, keep an Excel image list with viewer links, export QC screenshots, build the gallery, and measure the expansion factor from synapses in the pan stain.

The maintained version of every file here is in [ExpandedBrainQuant](https://github.com/allison714/ExpandedBrainQuant) under `legacy/ZarrBatchConverter/`, together with the later analysis scripts (antibody labelling, WT versus KO comparisons, pan-ASLM sampling) and the `ebq` package for 3D analysis. Use that repository; this one is kept only so existing links keep working.

`QUICKSTART.txt` describes how the tools are run. Per-PC settings belong in a local `settings.ini` created by `First_Time_Setup.bat`; that file is not committed.
